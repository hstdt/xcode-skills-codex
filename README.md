## Updates

GitHub Actions and local runs use the same export script. Only newer Xcode versions or builds replace the current snapshot; its source and update history are generated automatically. The [workflow](https://github.com/hstdt/xcode-skills-codex/actions/workflows/update.yml) runs daily or on demand. For local exports, use `scripts/update.py --xcode /path/to/Xcode.app`.
